# BankOps Knowledge Platform

Three independently deployable services share the existing PostgreSQL,
Elasticsearch, and MinIO data plane:

| Service | Port | Responsibility |
| --- | ---: | --- |
| File Service | 8951 | Upload bytes to MinIO and persist document metadata and ACLs in PostgreSQL |
| Knowledge MCP | 8952 | Access-controlled knowledge tools for DSH |
| Knowledge REST | 9052 | Internal indexing and Portal search API |
| Memory MCP | 8953 | User- and workspace-scoped long-term memory tools |
| Knowledge Worker | — | Asynchronous PDF, DOCX, and text extraction, indexing, retry, and deletion |

The current local identity comes from `BANKOPS_TENANT_ID`, `BANKOPS_USER_ID`,
`BANKOPS_DEPARTMENT_ID`, `BANKOPS_ROLES`, and `BANKOPS_WORKSPACE_ID`. This is a
development boundary, not production authentication. A shared deployment must
derive this context from the authenticated gateway and must not accept identity
claims generated by the model.

## Storage ownership

- MinIO `bankops-files`: authoritative original file bytes.
- PostgreSQL `documents` and `document_acl`: authoritative metadata and access rules.
- Elasticsearch `bankops-kb-documents-v1` and `bankops-kb-chunks-v1`: derived search index.
- Elasticsearch `bankops-agent-memories-v1`: current long-term memory store.

PDF, DOCX, text, Markdown, JSON, YAML, CSV, XML, log, and common configuration
files are indexed asynchronously. Scanned PDFs without a text layer fail with
an explicit OCR-required error. Unsupported formats are retained in MinIO with
a `STORED_ONLY` status and are not silently treated as searchable knowledge.

`document_index_jobs` is a PostgreSQL-backed work queue. Workers claim work with
`FOR UPDATE SKIP LOCKED`, recover expired leases, retry with exponential backoff,
and keep the authoritative document state visible to Portal users. Multiple
workers can run safely against the same database.

## MCP tools

Knowledge MCP exposes `search_knowledge`, `search_session_knowledge`,
`get_knowledge_document`, and `list_knowledge_documents`. A Portal-created
`ctx_...` knowledge context binds specific document versions for attachment-only
retrieval. Memory MCP exposes `recall_memories`,
`remember_memory`, `list_recent_memories`, and `forget_memory`.

Run the local smoke test after uploading the checked-in sample runbook:

```bash
node mcp/scripts/test-knowledge-memory.mjs
```
