# 输出模板

## 变更影响分析

- 变更单：
- 系统：
- 变更类型：
- 实施窗口：
- 综合风险：高风险 / 中风险 / 低风险 / 暂无法定级

### 一、变更概述

说明变更内容、对象和实施方式。

### 二、影响范围

分别列出直接影响和间接影响，并说明依赖路径。

### 三、资源与运行状态

列出主机、数据库、中间件、告警、日志和关键性能指标。

### 四、历史风险

列出类似变更、故障及其与本次变更的关联。

### 五、业务影响

说明可能受影响的业务能力、渠道和时间窗口。

### 六、风险依据

逐条使用“事实 → 推断 → 风险”的结构，并标明证据来源。

### 七、数据缺口

列出未取得、冲突或无法验证的数据，以及它们对结论的影响。

### 八、建议

给出变更前检查、实施控制、监控观察、回退触发条件和补数建议。
